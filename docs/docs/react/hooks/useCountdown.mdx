# useCountdown

지정한 간격(`intervalMs`)마다 값을 1씩 감소시키는 카운트다운 커스텀 훅입니다.

`countStop` 에 도달하면 자동으로 멈추며, 시작·일시정지·초기화·재시작·값 누적을 위한 제어 함수를 반환합니다.

## Interface

```ts title="typescript"
interface UseCountdownOptions {
  countStart: number;
  countStop?: number;
  intervalMs?: number;
  onComplete?: (count: number) => void;
  onTick?: (count: number) => void;
  pauseOnHidden?: boolean;
}

interface UseCountdownReturnType {
  count: number;
  isComplete: boolean;
  start: () => void;
  pause: () => void;
  reset: () => void;
  restart: () => void;
  addCount: (amount: number) => void;
}
```

```ts title="typescript"
function useCountdown(options: UseCountdownOptions): UseCountdownReturnType;
```

<br />

### Options

| Name | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `countStart` | `number` | - | 카운트다운 시작 값. 소수는 정수부만 사용합니다. |
| `countStop` | `number` | `0` | 카운트다운이 멈출 값. 소수는 정수부만 사용합니다. |
| `intervalMs` | `number` | `1000` | 카운트 간격(ms) |
| `onTick` | `(count: number) => void` | - | 값이 감소할 때마다 이번 tick 의 결과값을 인자로 호출됩니다. |
| `onComplete` | `(count: number) => void` | - | `countStop` 에 도달했을 때 그 값(`countStop`)을 인자로 호출됩니다. |
| `pauseOnHidden` | `boolean` | `false` | 실행 중에 화면이 숨겨지면 멈추고, 다시 보이면 이어서 진행합니다. |

<br />

### Returns

| Name | Type | Description |
| ---- | ---- | ----------- |
| `count` | `number` | 현재 카운트 값 |
| `isComplete` | `boolean` | 현재 카운트가 `countStop` 에 도달(이하)했는지 여부 |
| `start` | `() => void` | 카운트다운을 시작합니다. |
| `pause` | `() => void` | 카운트다운을 일시정지합니다. 현재 카운트는 유지되며, `start` 하면 이어서 진행합니다. |
| `reset` | `() => void` | 카운트다운을 멈추고 시작 값으로 되돌립니다. |
| `restart` | `() => void` | 시작 값으로 되돌리고 바로 시작합니다. 완료된 뒤에도 다시 시작할 수 있습니다. |
| `addCount` | `(amount: number) => void` | 현재 카운트에 `amount` 만큼 누적합니다. 소수는 정수부만 사용하며, `countStop` 아래로는 내려가지 않습니다. |

<br />

## Remarks

:::caution 주의사항
- tick 수를 세는 방식이라, 백그라운드 탭에서는 브라우저가 타이머를 늦추거나 멈춰 카운트가 실제 시간과 맞지 않습니다.
  - 화면을 보고 있을 때만 줄어들어야 한다면 `pauseOnHidden` 을 사용하세요.
  - 실제 시각과 맞아야 한다면 [`useTimer`](./useTimer) 를 사용하세요.
- 완료된 뒤에는 `start` 를 호출해도 다시 감소하지 않습니다. 처음부터 다시 시작하려면 `restart` 를 사용하세요.
:::

## Usage

### 기본 사용법

```tsx title="typescript"
import { useCountdown } from '@modern-kit/react';

const Example = () => {
  // 1초(intervalMs)마다 1씩 줄어드는 60초 카운트다운
  const { count, isComplete, start, pause, reset, restart, addCount } =
    useCountdown({
      countStart: 60,
      onTick: (count) => console.log('tick', count), // 이번 tick 결과값
      onComplete: (count) => console.log('done', count), // count === countStop
    });

  return (
    <div>
      <p>{isComplete ? '완료' : count}</p>
      <button onClick={start}>start</button>
      <button onClick={pause}>pause</button>
      <button onClick={reset}>reset</button>
      <button onClick={restart}>restart</button>
      <button onClick={() => addCount(5)}>+5</button>
    </div>
  );
};
```

<br />

### 화면이 숨겨지면 멈추기 (pauseOnHidden)

```tsx title="typescript"
import { useCountdown } from '@modern-kit/react';

const Example = () => {
  // 브라우저 탭이 백그라운드로 가면 멈추고, 돌아오면 이어서 진행
  const { count, start } = useCountdown({
    countStart: 60,
    pauseOnHidden: true,
  });

  return (
    <div>
      <p>{count}</p>
      <button onClick={start}>start</button>
    </div>
  );
};
```

### Example1 (백그라운드 동작 비교)

기본 동작과 `pauseOnHidden: true` 를 비교하는 예제입니다.

export const Example1 = () => {
  const defaultCountdown = useCountdown({ countStart: 60 });
  const pausedCountdown = useCountdown({ countStart: 60, pauseOnHidden: true });

  const startBoth = () => {
    defaultCountdown.restart();
    pausedCountdown.restart();
  };

  return (
    <div>
      <div style={{ marginBottom: '15px' }}>
        <h4 style={{ margin: '0 0 10px 0' }}>🧪 테스트 방법</h4>
        <ol style={{ margin: 0, paddingLeft: '20px', lineHeight: '1.6' }}>
          <li><strong>start</strong> 버튼을 눌러 두 카운트다운을 함께 시작하세요.</li>
          <li>다른 탭으로 이동해 <strong>10초 정도</strong> 기다리세요.</li>
          <li>다시 이 탭으로 돌아와 두 값을 비교하세요.</li>
        </ol>
      </div>

      <p>기본: <strong>{defaultCountdown.count}</strong></p>
      <p>pauseOnHidden: <strong>{pausedCountdown.count}</strong></p>
      <button onClick={startBoth}>start</button>

      <div style={{
        marginTop: '15px',
        padding: '12px',
        backgroundColor: '#f0f9ff',
        borderLeft: '3px solid #3b82f6',
        borderRadius: '4px',
        fontSize: '14px',
        color: '#1f2937'
      }}>
        <strong>💡 핵심:</strong> <code>pauseOnHidden</code> 카운트다운은 화면이 숨겨진 동안 멈췄다가 이어서 진행합니다.
        기본 카운트다운은 숨겨진 동안에도 감소하지만, 브라우저가 타이머를 늦추면 실제 흐른 시간보다 덜 감소할 수 있습니다.
      </div>
    </div>
  );
};
