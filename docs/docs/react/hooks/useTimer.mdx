# useTimer

지정한 시간(`durationMs`) 또는 종료 시각(`endAt`)까지 남은 시간을 계산하는 타이머 커스텀 훅입니다.

tick 횟수를 세는 방식이 아니라 **종료 시각과 현재 시각의 차이**로 남은 시간을 계산합니다. 따라서 브라우저가 백그라운드 탭의 타이머를 지연시키더라도, 화면으로 돌아오면 실제 남은 시간이 표시됩니다.

<br />

옵션에 따라 두 가지 방식으로 동작합니다.
- `durationMs`: 지정한 시간만큼 동작하는 타이머입니다. `start`, `pause`, `reset`, `addTime` 제어 함수를 제공합니다.
- `endAt`: 서버가 내려준 마감 시각처럼 정해진 종료 시각까지 남은 시간을 계산합니다. 마운트 시 바로 시작하며, 제어 함수는 제공하지 않습니다.

<br />

## Interface

```ts title="typescript"
interface UseTimerBaseOptions {
  intervalMs?: number;
  onTick?: (remainingMs: number) => void;
  onComplete?: () => void;
}

interface UseTimerWithDurationMsOptions extends UseTimerBaseOptions {
  durationMs: number;
  endAt?: never;
  autoStart?: boolean;
  pauseOnHidden?: boolean;
}

interface UseTimerWithEndAtOptions extends UseTimerBaseOptions {
  endAt: number | Date | null | undefined;
  durationMs?: never;
  autoStart?: never;
  pauseOnHidden?: never;
}

interface UseTimerReturnType {
  remainingMs: number;
  hours: number;
  minutes: number;
  seconds: number;
  isRunning: boolean;
  isComplete: boolean;
  start: () => void;
  pause: () => void;
  reset: () => void;
  addTime: (ms: number) => void;
}

type UseTimerEndAtReturnType = Pick<
  UseTimerReturnType,
  'remainingMs' | 'hours' | 'minutes' | 'seconds' | 'isComplete'
>;
```

```ts title="typescript"
// 1. durationMs 로 지정한 시간만큼 동작하는 타이머
function useTimer(options: UseTimerWithDurationMsOptions): UseTimerReturnType;

// 2. endAt 으로 지정한 종료 시각까지 남은 시간을 계산하는 타이머
function useTimer(options: UseTimerWithEndAtOptions): UseTimerEndAtReturnType;
```

<br />

### Options

| Name | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `durationMs` | `number` | - | **(durationMs 모드)** 타이머 시간(ms). 소수는 정수부만 사용합니다. `endAt` 과 함께 사용할 수 없습니다. |
| `autoStart` | `boolean` | `false` | **(durationMs 모드)** 마운트 시 바로 시작할지 여부 |
| `pauseOnHidden` | `boolean` | `false` | **(durationMs 모드)** 실행 중에 화면이 숨겨지면 멈추고, 다시 보이면 남은 시간부터 이어서 진행합니다. |
| `endAt` | `number \| Date \| null \| undefined` | - | **(endAt 모드)** 종료 시각(timestamp 또는 `Date`). 값이 바뀌면 새 종료 시각으로 다시 맞춥니다. `null` / `undefined` 이거나 유효하지 않은 값이면 멈춘 채 대기합니다. |
| `intervalMs` | `number` | `1000` | **(공통)** 남은 시간을 갱신하는 간격(ms). 화면 갱신 주기만 결정하며 정확도와는 무관합니다. |
| `onTick` | `(remainingMs: number) => void` | - | **(공통)** 남은 시간이 갱신될 때마다 남은 시간(ms)을 인자로 호출됩니다. |
| `onComplete` | `() => void` | - | **(공통)** 실행 중에 남은 시간이 0이 되면 호출됩니다. |

<br />

### Returns

| Name | Type | Description |
| ---- | ---- | ----------- |
| `remainingMs` | `number` | 남은 시간(ms) |
| `hours` | `number` | 남은 시간의 시 단위. 24 이상이 될 수 있습니다. |
| `minutes` | `number` | 남은 시간의 분 단위 (0~59) |
| `seconds` | `number` | 남은 시간의 초 단위 (0~59). 1초 미만이 남으면 1로 올림합니다. |
| `isComplete` | `boolean` | 남은 시간이 0인지 여부. endAt 모드의 대기 상태(`null` / `undefined`)에서는 `false` 입니다. |
| `isRunning` | `boolean` | **(durationMs 모드)** 타이머가 실행 중인지 여부 |
| `start` | `() => void` | **(durationMs 모드)** 타이머를 시작합니다. 일시정지 상태였다면 남은 시간부터 이어서 진행합니다. |
| `pause` | `() => void` | **(durationMs 모드)** 타이머를 일시정지합니다. 남은 시간은 유지됩니다. |
| `reset` | `() => void` | **(durationMs 모드)** 타이머를 멈추고 남은 시간을 `durationMs` 로 되돌립니다. |
| `addTime` | `(ms: number) => void` | **(durationMs 모드)** 남은 시간에 `ms` 만큼 누적합니다. 음수를 전달하면 시간을 줄입니다. |

## Remarks

:::caution 주의사항
- `durationMs` 와 `endAt` 은 함께 사용할 수 없습니다.
  - `endAt` 모드에서는 `autoStart`, `pauseOnHidden` 옵션을 사용할 수 없으며, 제어 함수(`start`, `pause`, `reset`, `addTime`)와 `isRunning` 도 반환하지 않습니다.
- 기본적으로 백그라운드에 있던 시간도 흐른 것으로 계산합니다. (50분 남은 상태로 10분 뒤 돌아오면 40분)
  - 화면을 보고 있을 때만 시간이 흘러야 한다면 `pauseOnHidden` 을 사용하세요.
  - 백그라운드 탭에서 `autoStart` 와 `pauseOnHidden` 을 함께 사용해 마운트되면, 화면이 처음 보일 때 시작합니다.
  - `pauseOnHidden` 으로 멈춘 상태에서 `pause` 를 호출하면, 화면이 다시 보여도 이어서 진행하지 않습니다.
- `addTime` 은 남은 시간을 0 아래로 내리지 않으며, 소수는 정수부만 사용하고 `NaN` / `Infinity` 는 무시합니다.
- `endAt` 모드의 `onComplete` 는 마운트 시 이미 지난 `endAt` 이거나, 대기 상태(`null` / `undefined`)로 바뀐 경우에는 호출되지 않습니다.
  - 실행 중에 이미 지난 `endAt` 으로 바뀌면 완료로 처리하고 `onComplete` 를 호출합니다.
:::

<br />

:::tip intervalMs 와 정확도
- 남은 시간은 매 갱신마다 `종료 시각 - 현재 시각`으로 다시 계산하므로, `intervalMs` 는 화면 갱신 주기만 결정합니다.
- 갱신 시점은 남은 시간이 `intervalMs` 의 배수가 되는 순간에 맞춰지므로, 초 단위 표시가 밀리지 않습니다.
- 밀리초 단위의 부드러운 표시가 필요하다면 `intervalMs` 를 작게(예: `100`) 설정하고 `remainingMs` 를 사용하세요.
:::

## Usage

### durationMs 타이머

```tsx title="typescript"
import { useTimer } from '@modern-kit/react';

const Example = () => {
  const { hours, minutes, seconds, isRunning, start, pause, reset, addTime } =
    useTimer({
      durationMs: 60 * 60 * 1000, // 1시간
      onComplete: () => alert('끝'),
    });

  return (
    <div>
      <p>
        {hours}:{minutes}:{seconds}
      </p>
      <button onClick={isRunning ? pause : start}>
        {isRunning ? 'pause' : 'start'}
      </button>
      <button onClick={reset}>reset</button>
      <button onClick={() => addTime(10 * 60 * 1000)}>+10분</button>
    </div>
  );
};
```

<br />

### 화면이 숨겨지면 멈추기 (pauseOnHidden)

```tsx title="typescript"
import { useTimer } from '@modern-kit/react';

const Example = () => {
  // 백그라운드에서는 멈추고, 돌아오면 남은 시간부터 이어서 진행
  const { minutes, seconds } = useTimer({
    durationMs: 10 * 60 * 1000,
    autoStart: true,
    pauseOnHidden: true,
  });

  return (
    <p>
      {minutes}:{seconds}
    </p>
  );
};
```

### endAt 타이머

```tsx title="typescript"
import { useTimer } from '@modern-kit/react';

const Example = ({ id }: { id: string }) => {
  // 데이터를 불러오는 동안(auction?.endAt === undefined)은 대기하고, endAt 이 들어오면 바로 시작
  const { data: auction, refetch } = useAuctionQuery(id);

  const { hours, minutes, seconds, isComplete } = useTimer({
    endAt: auction?.endAt,
    onComplete: () => refetch(),
  });

  if (isComplete) return <p>마감되었습니다.</p>;

  return (
    <p>
      마감까지 {hours}:{minutes}:{seconds}
    </p>
  );
};
```

export const pad = (value) => String(value).padStart(2, '0');

### Example (durationMs 타이머)

export const Example = () => {
  const [log, setLog] = useState('');
  const { hours, minutes, seconds, isRunning, isComplete, start, pause, reset, addTime } =
    useTimer({
      durationMs: 10 * 1000,
      onComplete: () => setLog('⏰ 타이머 완료!'),

  return (
    <div>
      <div style={{ marginBottom: '15px' }}>
        <h4 style={{ margin: '0 0 10px 0' }}>🧪 테스트 방법</h4>

          <li><strong>pause</strong> 후 다시 <strong>start</strong>를 누르면 남은 시간부터 이어서 진행됩니다.</li>
          <li><strong>+5초 / -5초</strong> 버튼으로 남은 시간을 조절해 보세요.</li>
        </ol>
      </div>

      <p style={{ fontSize: '32px', fontWeight: 'bold', margin: '10px 0' }}>
        {pad(hours)}:{pad(minutes)}:{pad(seconds)}

      </p>

      <div style={{ display: 'flex', gap: '8px' }}>

        <button onClick={() => { reset(); setLog(''); }}>reset</button>
        <button onClick={() => addTime(5000)}>+5초</button>

        남은 시간이 0이 되면 <code>onComplete</code>가 호출됩니다.
      </div>
    </div>
  );

### Example1 (백그라운드 동작 비교)

기본 동작과 `pauseOnHidden: true` 를 비교하는 예제입니다.

export const Example1 = () => {
  const defaultTimer = useTimer({ durationMs: 60 * 1000, autoStart: true });
  const pausedTimer = useTimer({ durationMs: 60 * 1000, autoStart: true, pauseOnHidden: true });

  return (
    <div>
      <div style={{ marginBottom: '15px' }}>
        <h4 style={{ margin: '0 0 10px 0' }}>🧪 테스트 방법</h4>
        <ol style={{ margin: 0, paddingLeft: '20px', lineHeight: '1.6' }}>
          <li>다른 탭으로 이동해 <strong>10초 정도</strong> 기다리세요.</li>
          <li>다시 이 탭으로 돌아와 두 타이머를 비교하세요.</li>
        </ol>
      </div>

      <p>
        기본: <strong>{pad(defaultTimer.minutes)}:{pad(defaultTimer.seconds)}</strong>
        <button style={{ marginLeft: '8px' }} onClick={() => { defaultTimer.reset(); defaultTimer.start(); }}>restart</button>
      </p>
      <p>
        pauseOnHidden: <strong>{pad(pausedTimer.minutes)}:{pad(pausedTimer.seconds)}</strong>
        <button style={{ marginLeft: '8px' }} onClick={() => { pausedTimer.reset(); pausedTimer.start(); }}>restart</button>
      </p>

      <div style={{
        marginTop: '15px',
        padding: '12px',
        backgroundColor: '#f0f9ff',
        borderLeft: '3px solid #3b82f6',
        borderRadius: '4px',
        fontSize: '14px',
        color: '#1f2937'
      }}>
        <strong>💡 핵심:</strong> 기본 타이머는 백그라운드에 있던 시간도 흐른 것으로 계산하고,
        <code>pauseOnHidden</code> 타이머는 화면이 숨겨진 동안 멈췄다가 남은 시간부터 이어서 진행합니다.
      </div>
    </div>
  );
};

### Example2 (endAt 타이머)

서버에서 마감 시각을 불러오는 상황을 시뮬레이션한 예제입니다.

export const Example2 = () => {
  const [endAt, setEndAt] = useState(null);
  const [log, setLog] = useState('');
  const { minutes, seconds, isComplete } = useTimer({
    endAt,
    onComplete: () => setLog('⏰ 마감되었습니다!'),
  });

  const fetchEndAt = (ms) => {
    setLog('⏳ 마감 시각을 불러오는 중...');
    setEndAt(null);
    setTimeout(() => {
      setEndAt(Date.now() + ms);
      setLog('');
    }, 1000);
  };

  return (
    <div>
      <div style={{ marginBottom: '15px' }}>
        <h4 style={{ margin: '0 0 10px 0' }}>🧪 테스트 방법</h4>
        <ol style={{ margin: 0, paddingLeft: '20px', lineHeight: '1.6' }}>
          <li>버튼을 눌러 마감 시각을 불러오세요. (1초 지연)</li>
          <li>불러오는 동안(<code>endAt: null</code>)은 대기하고, 값이 들어오면 바로 시작합니다.</li>
          <li>실행 중에 다른 버튼을 누르면 새 마감 시각으로 다시 맞춥니다.</li>
        </ol>
      </div>

      <p style={{ fontSize: '32px', fontWeight: 'bold', margin: '10px 0' }}>
        {pad(minutes)}:{pad(seconds)}
      </p>
      <p>
        isComplete: <code>{String(isComplete)}</code>
      </p>

      <div style={{ display: 'flex', gap: '8px' }}>
        <button onClick={() => fetchEndAt(10 * 1000)}>10초 뒤 마감</button>
        <button onClick={() => fetchEndAt(60 * 1000)}>1분 뒤 마감</button>
      </div>
      <p>{log}</p>

      <div style={{
        marginTop: '15px',
        padding: '12px',
        backgroundColor: '#f0f9ff',
        borderLeft: '3px solid #3b82f6',
        borderRadius: '4px',
        fontSize: '14px',
        color: '#1f2937'
      }}>
        <strong>💡 핵심:</strong> <code>endAt</code> 모드는 종료 시각만 전달하면 바로 동작합니다.
        <code>null</code> / <code>undefined</code> 이면 대기하며, 이 상태에서 <code>isComplete</code>는 <code>false</code> 입니다.
      </div>
    </div>
  );
};
